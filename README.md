\# 🌱 AgriSense - Smart Crop Planning Advisor



AgriSense is a machine learning-based crop recommendation system that suggests the most suitable crop based on soil nutrients and climatic conditions.



\## Features



\- Predicts the best crop using Random Forest Classifier

\- Streamlit-based web interface

\- 99%+ model accuracy

\- Real-world agriculture use case



\## Input Parameters



\- Nitrogen (N)

\- Phosphorus (P)

\- Potassium (K)

\- Temperature

\- Humidity

\- pH

\- Rainfall



\## Tech Stack



\- Python

\- Pandas

\- Scikit-learn

\- Streamlit
